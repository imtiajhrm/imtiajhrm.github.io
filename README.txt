HASSAN IMTIAJ ISLAM — FREE CAREER PORTFOLIO WEBSITE

This is a static website starter package for free hosting with GitHub Pages.
No annual hosting fee is required for a basic public portfolio. The free address will look like:
https://YOUR-GITHUB-USERNAME.github.io
A personal .com domain is optional and normally costs money each year.

FILES
- index.html: website structure and content
- style.css: responsive design
- README.txt: these instructions

PUBLISH FOR FREE USING GITHUB PAGES
1. Open https://github.com/ and create a free account, or sign in.
2. Create a new public repository named exactly:
   YOUR-GITHUB-USERNAME.github.io
   Replace YOUR-GITHUB-USERNAME with your GitHub username.
3. Open the new repository and choose Add file -> Upload files.
4. Extract this ZIP on your computer/phone, then upload index.html and style.css
   (you can also upload README.txt, but it is not needed for the website).
5. Commit/upload the files to the repository.
6. Open repository Settings -> Pages.
7. Under Build and deployment, choose Deploy from a branch, select the main branch
   and /(root), then Save if these options are shown.
8. Wait a few minutes, then open:
   https://YOUR-GITHUB-USERNAME.github.io
   Replace the placeholder with your actual GitHub username.

IMPORTANT BEFORE PUBLICATION
- Replace the portrait placeholder with your professional photo.
- Confirm all employer names, official job titles and employment dates.
- Replace achievement prompts with accurate, non-confidential results.
- Confirm education and completed certifications; do not list an unfinished course as a certification.
- Replace the email placeholder and LinkedIn URL in index.html.
- Do not publish personal phone/address details unless you want them public.
- The website and its content will be public. Do not upload confidential company or employee data.
- A custom domain such as imtiaj.com is not included in free hosting and usually requires an annual domain fee.
